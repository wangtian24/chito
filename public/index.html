chitoVersion 0.1.0

A simple web UI for Claude Code, Pi, and Codex. It lists the sessions on this machine, shows each one as a conversation, gives every session and message a permalink, and reopens a session in your terminal.

It runs locally and reads transcripts from each CLI's session directory. Nothing is sent anywhere.

chito is open source and public under the MIT license. Code, issues and changes live at github.com/wangtian24/chito.
